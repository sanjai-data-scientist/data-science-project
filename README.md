### 📌 Project Overview

- **Language:** Python

### 🔑 Key Work Done
1. Data Cleaning: Handled missing values, date formats, removed duplicates
2. EDA & Visualization: Sales trends analysis
3. Forecasting Model

**Files:** `project01.py`, `sales_data.csv`
